# 🚀 Productivity Dashboard

A clean, responsive, and all-in-one web-based **Productivity Dashboard** designed to streamline your daily workflow, tracking, and focus. Built entirely using vanilla frontend technologies and deployed live on GitHub Pages.

📍 **Live Demo:** [View Live Project](https://shabnamsakhre.github.io/Productivity_Dashboard/)

---

## ✨ Features

The dashboard bundles core utility tools into a single, cohesive user interface:

* **📋 To-Do List:** Create, track, and manage your daily tasks seamlessly.
* **📅 Daily Planner:** Schedule your day's time slots and prioritize critical events.
* **🎯 Daily Goals:** Set core targets for the day and check them off as you progress.
* **⏱️ Pomodoro Timer:** Keep track of deep work sessions and break intervals to prevent burnout.
* **🌟 Motivational Quotes:** Displays dynamic daily quotes to keep you driven and focused.
* **🌦️ Live Weather:** Leverages your location to show current city temperatures and weather details.

---

## 🛠️ Tech Stack

This project is lightweight, fast, and does not require any installation or build setup:

* **HTML5:** Semantic structures for accessible UI layouts.
* **CSS3:** Modern styling, flexbox/grid alignments, and smooth transition animations.
* **JavaScript (ES6+):** Handle state management, core application logic, and asynchronous data fetching.
* **Third-Party APIs:**
  * **WeatherAPI:** For local real-time meteorological conditions.
  * **DummyJSON Quotes API:** For secure, valid, and inspiring random quotes.

## 🚀 Getting Started

If you want to view, test, or modify this project locally on your machine, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com
```

### 2. Navigate to the project folder
```bash
cd Productivity_Dashboard
```

### 3. Run the project
Since it is a standard static web application, you can simply double-click the `index.html` file to open it in your browser. 

*Alternatively, you can use the **Live Server** extension in VS Code for a better development experience.*

---

## 🔒 Security Note regarding API Keys

This application uses client-side API requests to fetch real-time weather information. For development simplicity on a static GitHub Pages deployment, the public API key is stored inline. In an enterprise or production-heavy context, these keys should ideally be kept secure via a server-side proxy or backend environment variables.
